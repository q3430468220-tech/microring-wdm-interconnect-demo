# 微环WDM光互连交互演示

[在线演示](https://q3430468220-tech.github.io/microring-wdm-interconnect-demo/)

参考Ayar公开架构的四波长链路教学演示：外置供光、PN微环发射、共用光纤、微环选波接收及热调谐。每通道25 Gb/s NRZ，合计单向100 Gb/s原始速率。参数为工程设定，结果为电路级数值仿真。

## 使用

打开在线演示，选择正常、温漂、再锁定、窄间隔或低功率配置，再切换λ₁—λ₄通道。页面显示真实比特判决恢复的图像、错误位置、光谱、眼图、PRBS误码计数和独立慢时标热调谐轨迹。

`index.html`是独立文件，数据、样式、脚本及图片均内嵌，也可下载后在本地浏览器打开。没有服务器端计算，不上传访问者数据。各配置为已计算的固定场景，切换界面不重新运行链路仿真。

## 数据与边界

| 配置 | PRBS错误位／65,536 | 图像错误位／32,768 |
|---|---:|---:|
| 正常 | 0 | 0 |
| 温漂＋3 K | 3,137 | 2,170 |
| 再锁定 | 0 | 0 |
| 50 GHz通道间隔 | 0 | 0 |
| 每波长光功率降低15 dB | 20,996 | 8,675 |

每场景以已知导频校准采样与门限，随后冻结用于独立PRBS和图像。每通道16,384个PRBS位零错，在独立伯努利试验近似下的单侧95%上界约为1.83×10⁻⁴，不能证明BER达到10⁻¹²。

模型保留全部Tx/Rx环级联和多载波拍频。接收端采用微环滤波＋独立PD/TIA的等效结构，未复刻商业芯片。OMA为等效接收采样指标，非标准发射OMA。热调谐是无噪监测下的扫描再捕获，未实现持续实时跟踪。

正式128点/UI；128→256细化抽查在50 GHz档仍有2／3,584处固定共同门限判决差异，低BER收敛未证明。未建模完整周期谱、偏压相关吸收、激光相位噪声、RIN、抖动、ADC量化、热串扰及完整能耗／延迟。

图像取自MNIST测试样本组成的64×64灰度图。公开架构资料及核读记录见 [REFERENCES.md](REFERENCES.md)。

## 部署

通过GitHub Pages，从`main`分支的根目录部署。入口为`index.html`，无需依赖安装或构建步骤。
